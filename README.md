# Premier Mesh

Touch, stretch, illuminate, and film a living digital mesh. Premier Mesh supports simultaneous multipoint pulling, twenty visual themes, adjustable complexity, eight connection styles, local video mapping, PNG capture, and browser recording.

**Stereo 3D view:** tap the 3D button (or open the 3D tab) to split the stage into a side-by-side stereo pair for cross-eyed or parallel free-viewing, with adjustable depth, screen plane, and pair width. PNG captures and recordings include both views.

Selected video files are processed locally in the browser and are not uploaded by the app.
